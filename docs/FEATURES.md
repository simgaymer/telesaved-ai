# Feature Overview

## Library and ingestion

- Download videos from Telegram Saved Messages, chats, groups, and channels.
- Configure multiple Telegram sources.
- Track downloads as Jobs.
- Store file metadata including source, duration, size, hashes, and Telegram message metadata.

## AI media intelligence

- Extract frames with FFmpeg.
- Generate thumbnails and hover preview GIFs.
- Use CLIP embeddings for semantic search and similarity.
- Use YOLO for object/person-assisted tagging.
- Use FAISS for vector search.
- Use Whisper for audio transcription.

## Administration

- Dashboard stats by source and tag.
- Storage safety and auto-pause support.
- Jobs/queue page.
- Logs, backups, import/export, settings, source pipelines, and user management.

## Review and cleanup

- Trash/restore instead of immediate destructive delete.
- Exact duplicate cleanup.
- Possible duplicate review with confidence and signals.
- Review Studio and Cleanup Studio.
- Smart collections, personal states, favorites, ratings, watch-later, and watched tracking.

## Search

TeleSaved 4.4.2 includes hybrid advanced search by name, date, duration, source, tags, state, favorites, rating, watched status, watch-later, and file existence.
